# grupus
Firefox extension for managing tab groups.
Grupus can save and restore tab groups.

Not sure why firefox has ai powered tab suggestion button but no save group button.

# Usage

- Use `Add Group` to add new group.
- You can click on the group name to change it.
- Use `APPLY` to create group with tabs
  - Somebody suggested to change this to some thing else because apply is confusing, so that is something to look forward in the future.
- Use `DELETE` to delete the goup.
- Inside group card, click on the bottom empty space to add new tab.
- Use `REMOVE` to remove tab.
